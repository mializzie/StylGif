How to Use This File

  • 1Fill in the team member fields below — name, role, bio, and photo.
  • 2To add a photo: upload an image file. Note the filename, then place the image in the same folder as these HTML files. Set the path like img/yourphoto.jpg.
  • 3Click Export JSON at the bottom to copy the data object.
  • 4Open index.html and replace the const TEAM = [...] array with your exported data.
  • 5Optionally, edit the Featured GIFs section to rename the showcase tiles shown on the home screen.
